# IT SUCKS!

**Independent articles, lightweight software, and practical fixes for things that probably should not have been annoying in the first place.**

I build small, focused tools with an emphasis on privacy, simplicity, and avoiding unnecessary bloat. The project includes Chrome extensions, WordPress plugins, web utilities, and articles at [IT SUCKS!](https://www.itsucks.fyi/).

## Current Projects

- **[Video Downloader for X](https://github.com/ItSucksFYI/Video-Downloader-for-X)**  
  Download videos from X.com directly, with optional image downloads.

- **[Milan's RedGifs Video Downloader](https://github.com/ItSucksFYI/Milans-RedGifs-Video-Downloader)**  
  A lightweight RedGifs downloader built around a simple one-click workflow.

- **[No Autoplay, Thanks!](https://github.com/ItSucksFYI/No-Autoplay)**  
  Stops unwanted autoplay without trying to rewrite half the browser.

- **[Project IT SUCKS!](https://github.com/ItSucksFYI/Project-It-Sucks)**  
  Background, project history, visual identity, and the ideas behind IT SUCKS!

## What I Like

- no ads;
- no analytics or telemetry;
- no unnecessary accounts;
- no subscription nonsense;
- no giant frameworks for tiny jobs;
- software that does one thing properly.

WordPress plugins and more small tools are on the way.
